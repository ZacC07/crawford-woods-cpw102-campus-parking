# Product Requirements

**Project:** Campus Parking Helper

**Team members: Zachary Crawford, marvell woods**

**Date: 30 Semptember 2026**

## User and problem

Who is the user? Parking students and visitors of campus.

What problem does the user have? It's difficult to calculate the price of parking on campus.

## Goal

Our program will help the user: Calculate how much to pay for parking.

## Requirements

Write three things the program must do. Make each one specific enough to test.

1. The program must: take a time as an input
2. The program must: multiply that input by the hourly rate
3. The program must: output the correctly estimated price price

## Not included

What will this version **not** do?

- it can't take in times like 1 hour 30 minutes, instead you'll have to use hours like 1.5 hours etc.

## Success

We will know the product works when: it outputs the correct price based on the input time.
